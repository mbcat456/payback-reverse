Trackingtechnologien in der PAYBACK App

Adjust

Das Adjust SDK ist ein Analysetool, das Dienste bereitstellt, mit denen Events wie App-Installationen, App-Anmeldungen und Klicks auf eCoupons verfolgt werden können.

Erhobene Daten

Standort-Daten, Server-Protokolle, Ressourcen auf unserer Website auf die Sie zugreifen und die Sie nutzen, IP-Adresse, Betriebssystem und Browsertyp

Genutzte Technologien

SDK

Aufbewahrungsdauer

Die Daten werden nach maximal 25 Monaten gelöscht

Datenschutzbestimmungen

https://www.adjust.com/terms/privacy-policy

Adjoe

Das adjoe SDK stellt Dienste zur Verfügung, die die Nutzung von Spieleangeboten ("Spielewelt") ermöglichen.

Erhobene Daten

Auf dem mobilgerät installierte Apps (inklusive Nutzungsdauer und Nutzungshistorie), Device-ID, Modell und Produktname des Android Endgeräts, Betriebssystemversion, Browsertyp, Displayauflösung, IP-Adresse,

Genutzte Technologien

SDK

Aufbewahrungsdauer

So lange, wie die Daten für die Nutzung von Playtime, zur Erfüllung der Zwecke, für die die jeweiligen Daten erfasst wurden oder Nutzerwünsche oder im Rahmen berechtigter Interessen benötigt werden und maximal so lange, wie es nach dem Gesetz zulässig bzw. erforderlich ist.

Datenschutzbestimmungen

https://adjoe.zone/legal/de/payback/data_privacy.html

Adition

Adition stellt Dienste zur Verfügung um nicht personalisierte und personalisierte Werbung und Inhalte anzuzeigen.

Erhobene Daten

Interaktion mit Werbeanzeigen, verfügbare Coupons (die für eine spezifischere Ausrichtung der Anzeigen verwendet werden)

Genutzte Technologien

SDK

Aufbewahrungsdauer

Die Daten werden nach maximal 24 Monaten gelöscht

Datenschutzbestimmungen

https://www.adition.com/datenschutz-plattform/

Adobe

Adobe Analytics stellt Tracking-Dienste zur Verfügung, die es ermöglichen, die Interaktionen der Nutzer innerhalb der PAYBACK App zu verfolgen.

Erhobene Daten

Installierte Partner-Apps, Benutzeraktionen (z. B. Login), Seitenaufrufe, Google Pay / Apple Pay-Status, Geräteinformationen --> erteilte Berechtigungen (Wifi, BLE, Standort, Login Status

Genutzte Technologien

Adobe Tracking SDK

Aufbewahrungsdauer

Die Daten werden nach maximal 25 Monaten gelöscht

Datenschutzbestimmungen

https://experienceleague.adobe.com/docs/analytics/technotes/privacy-overview.html

Airship

Airship ist der Anbieter von PAYBACK, um mobile Push-Nachrichten zu versenden. Dafür wird das Airship SDK verwendet, um angemeldete App-Instanzen zu verfolgen sowie die Ergebnisse der mobilen Push-Nachrichten (versendet/abgelehnt, App geöffnet/geschlossen) zu erfassen.

Erhobene Daten

PAYBACK Member ID (zur Adressierung von mobilen Push-Anfragen), Vorname (zur Personalisierung des Nachrichtentextes), OS-Benachrichtigungsberechtigung, verschiedene Geräteeigenschaften, gesendete mobile Push-Nachrichten, App geöffnet/geschlossen (als Reaktion auf welche mobile Push-Nachricht), Datenpaket der mobilen Push-Nachricht

Genutzte Technologien

Airship SDK

Aufbewahrungsdauer

Die Daten werden nach maximal 3 Monaten gelöscht

Datenschutzbestimmungen

https://www.airship.com/legal/

Google Firebase

Eine Reihe von Google-SDKs für iOS und Android, die die Verwendung von Push, Remote-Konfiguration (A/B-Tests), Absturzberichte, App-Statistiken und Benutzer-Tracking ermöglichen

Erhobene Daten

App Performance, Abstürze, Fehler, Benutzeraktionen (z. B. Login), Seitenaufrufe

Genutzte Technologien

Firebase SDK

Aufbewahrungsdauer

Die Daten werden nach maximal 14 Monaten gelöscht

Datenschutzbestimmungen

https://firebase.google.com/support/privacy

Paymorrow

Erfasst den digitalen Fingerabdruck des Geräts (personalisierte Benutzerdaten), um Betrug und automatisierte Angriffe zu verhindern.

Erhobene Daten

Betriebssystem, Informationen zur App-Version, Informationen zur Betriebssystem Version, Informationen zum Display (Bildschirm), Wifi-Netzwerkinformationen (verbundene Wifi-Netzwerke, Mac-Adresse), Informationen über Bluetooth-Geräte (Mac-Adresse und gekoppelte Bluetooth-Geräte), Speicher-Informationen, Geolokalisierung, Seriennummer der Hardware, Android-Kennungen (z. B. eindeutige AndroidID), Zeitpunkt der Geräteinstallation, zufällig generierte Gerätekennung

Genutzte Technologien

SDK

Aufbewahrungsdauer

Die Daten werden nach maximal 36 Monaten gelöscht

Datenschutzbestimmungen

https://www.intercard.de/de/datenschutzbedingungen-online-kaeufer
