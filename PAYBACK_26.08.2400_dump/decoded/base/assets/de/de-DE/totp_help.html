Was ist der 2SV Code?

Hier findest du alles zum 2SV Code der 2-Schritt-Verifizierung

Was ist der 2SV Code?

In einigen Situationen kannst du die Login-Anfragen nicht mit der Standardmethode genehmigen (d.h. durch eine Push Nachricht oder eine Nachricht innerhalb der App). Dann benötigst du den 2SV Code als alternative Methode zur Genehmigung. Hier erklären wir dir, in welchen Situationen du den 2SV Code brauchst.

Wie funktioniert die 2-Schritt-Verifizierung beim Punkte Einlösen an der Kasse?

Wenn du an der Kasse Punkte einlöst, dann musst du den 2SV Code eingeben, nachdem du deine (digitale) Karte gescannt hast. Gib den 2SV Code am Display in das Feld ein, das "PIN" heißt.
Hiervon ausgenommen ist die Punkteeinlösung innerhalb der App! Dabei brauchst du keinen 2SV Code.

Wie funktioniert die 2-Schritt-Verifizierung am Servicepunkt?

An den PAYBACK Servicepunkten in den Filialen von REWE, PENNY, real, Globus und Alnatura Super Natur Markt kannst du den 2SV Code anstelle deiner bisherigen PIN nutzen.
Falls du ein Passwort verwendest, wirst du danach aufgefordert, dich mit der App zu authentifizieren, indem du eine Push-Nachricht bestätigst. Möglicherweise kannst du das nicht tun, weil die Internetverbindung nicht stabil ist. Dann kannst du stattdessen mit der Authentifizierung durch den 2SV Code fortfahren.
Der 2SV Code funktioniert nämlich auch ohne Internetverbindung.

Wie sicher ist der 2SV Code?

Für größtmögliche Sicherheit wird alle 60 Sekunden automatisch ein neuer Code generiert. Nur mit dem jeweils aktuell gültigen Code aus deinem vertrauenswürdigen Gerät kannst du dich authentifizieren. Damit du an der Kasse nicht in Stress gerätst, wenn der aktuelle Code nur noch kurze Zeit gültig ist, kannst du dir auch schon früher einen neuen Code generieren lassen.
